# Jacob, A GPT-Powered Portfolio Chat

This project transforms a traditional personal portfolio into an interactive experience by allowing visitors to have a conversation with an AI-powered version of myself. Built using React and the OpenAI API, the chatbot is trained with my resume, professional background, and personality traits to engage in meaningful, authentic conversations.

---

## Motivation

Instead of a static portfolio showcasing projects and experiences, I wanted to create something more personal and engaging. By integrating GPT, I aimed to offer visitors a dynamic, conversational interaction, making the portfolio experience memorable and reflective of who I am.

---

## Features

- **Interactive Chat:** Visitors can ask questions and engage in conversations about my professional experience, interests, or casual topics.
- **Personalized Responses:** The chatbot uses a carefully structured prompt incorporating my resume and personality, allowing it to provide authentic and natural-sounding responses.
- **Intuitive UI:** Built with React and styled using Tailwind CSS, providing a simple, friendly user experience.
